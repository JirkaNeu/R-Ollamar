# R-Ollamar

#### Using R and Ollama via the ollamar:

https://github.com/hauselin/ollama-r

https://cran.r-project.org/web/packages/ollamar/vignettes/ollamar.html

---

So far:

* R-simple_chat.R -> a simple chat script with local ai, user input via prompt window (tcltk-library, realised in the prompt_win.R file) - the chat is finally printed in a log file
* R-ai-dialogue -> two different local models having a conversation, talking about this and that
* R-read_image.R -> a basic try to generate r code remaking a pie plot (a_pie_plot_src.png) by a local vision model - result: a2_pie_plot_rmk.png
